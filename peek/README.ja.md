# peek

[![English](https://img.shields.io/badge/lang-English-lightgrey)](README.md)
[![日本語](https://img.shields.io/badge/lang-%E6%97%A5%E6%9C%AC%E8%AA%9E-blue)](README.ja.md)

2つの部分からなる [Claude Code](https://claude.com/claude-code) の mod です。トランスクリプトでは、ツール呼び出しを1行ずつに畳み、結果のブロックを隠します。Write や Edit のファイルの中身や差分が会話に広がらなくなります。ペインでは、会話を1ページずつ読めます。あなたのプロンプトの下に、Claude の発言から次の発言までに Claude がしたこと(thinking、各ツール呼び出しの入力と結果は押すだけで出したり畳んだり)を並べ、前後のページへはボタンで移れます。ctrl+o のトランスクリプトに切り替える必要はありません。

![peek](docs/screenshot.png)

## 機能

- **畳んだツールの行**: トランスクリプトのツール呼び出しは1つ1行で、`● Write(…/src/app.ts)` のように表示します。点の色は実行中が黄、終わったら緑、失敗したら赤で、後ろに `error`、`interrupted`、`background` などの注記を付けます。長いパスはファイル名が残るよう頭の方を切ります
- シェルのコマンドは、コマンドの名前とそれを繋ぐ記号だけを残し、引数は `..` にします(`● Bash(cd .. && npm .. | tail ..)`)。引用符、`$(…)`、ヒアドキュメントの本文、コメントの中は見ません
- 本体がまとめた行(`Read 3 files, ran 2 shell commands`)は展開し、呼び出しを1つずつ1行で表示します
- **発言の色分け**: 見分けやすいよう、あなたのプロンプトは水色の縦線と青みの灰色の帯、Claude の発言は橙の縦線で表示します。どのブロックも、文字の上下に1行、左右に1文字ずつ、その色の余白を取ります。ターンの最後の発言(Claude の答え)は薄い橙の帯、途中の発言(後にツール呼び出しが続いた発言)は答えと紛れないよう灰色の帯にします。途中の発言は、後に続くツール呼び出しが届いた時点で灰色になります
- ツール呼び出しの合間の Claude の発言の代わりに本体が出す要約の行は、Claude の返答と紛れないよう、上下に1行ずつ空けた灰色の帯で表示します
- これらの行をクリックすると、それを含むページ(直前の Claude の発言から直後の発言まで)を、一番上にそのターンのプロンプトを置き、その呼び出しの入力・結果を出し、その呼び出しが見える所までスクロールして開きます。同じ行をもう一度クリックすると閉じます
- **トランスクリプトの4段階の表示**:
  1. **all**: 何も畳みません。ツール呼び出しとその結果のブロックを Claude Code の表示のまま出します(プロンプトと Claude の発言の色分けはそのまま)
  2. **cpt tool**: あなたのプロンプト、Claude の途中の発言、1行に畳んだツール呼び出し(`Bash(…)`、`Read(…)`)、Claude の最後の発言(既定)
  3. **no tools**: あなたのプロンプト、Claude の途中の発言(と要約の行)、Claude の最後の発言。ツール呼び出しの行は隠します
  4. **answers**: あなたのプロンプトと Claude の最後の発言だけ
- 段階は、すべてのプロンプトと Claude の最後の発言のブロックの右下にあるボタン `show  all  cpt tool  no tools  answers` で切り替えます。今の段階はブロックの縦線の色で塗られ、別のボタンを押すとその段階になります。トランスクリプト全体が切り替わり、選んだ段階は次のセッションにも引き継ぎます。`/peek 1` から `/peek 4` でも設定できます。ctrl+o では今までどおりすべての行を表示し、サブエージェントのトランスクリプトの呼び出しは1つずつの行のままです
- **ページ**: 上から、そのターンのプロンプト(長いものは頭の数行だけで、押すと全部出ます)、途中経過の前の Claude の発言、途中経過(thinking(薄い色)とツール呼び出し)を順に、途中経過の後の Claude の発言です。発言はトランスクリプトと同じ色分けで、プロンプトは水色の縦線と青みの灰色の帯、Claude の発言は橙の縦線で、ターンの最後の発言は薄い橙の帯、途中の発言は灰色の帯に表示します。ターンの最初のページはプロンプトから始まり、実行中のターンの最後のページは後の発言がまだ無いページになります
- 見出しの `◂` / `▸`、または一番下の `◂ previous` / `next ▸` で、前後のページ(ターンをまたいで)に移ります。見出しには `Turn 3/12 · page 2/4` のように今の位置を表示します。見出しと一番下の行はペインの上端と下端に留まり(スクロールしてもちらつきません)、ページはその間でスクロールします。ドックしたペインでは、見出しを枠の上の辺に、前後のページへのボタンを下の辺に埋め込み、間の行をすべてページに使います
- ツール呼び出しは、`● Edit …/src/app.ts  ▸ input  ▸ 12 lines` のような色付きの見出しの行だけを表示します。`▸ input` で入力を JSON で、`▸ 12 lines` で結果を出し、それぞれ別の背景色で表示します(失敗した結果は赤みのある背景)。見出しの行を押すと、両方をまとめて出したり畳んだりします。色は明るいテーマと暗いテーマに合わせて変えます
- ホイールか矢印でスクロールします。最新のページを見ている間は、ターンが進むと新しいページに移り、一番下までスクロールしていれば伸びるページについていきます。前のページを見ている間は、読んでいる位置に留まります。`⇥` で最新のページに戻ってまたついていき、`⟳` で会話を読み直します。`close`(枠の `✕` より大きく、指を載せると赤くなります)でペインを閉じます
- サブエージェントのトランスクリプトの行からは、そのエージェントの会話を開きます
- **表示する場所**は、Claude Code がターミナルの幅で決めます。fullscreen 表示で 110 列以上ならトランスクリプトの右にドックし、結果を長めに表示します。ドックしたペインは、トランスクリプトや他のペインと紛れないよう、全体を枠線で囲みます。枠はスクロールしても動きません。枠の左の辺は、Claude Code がトランスクリプトとペインの間に引く線(ドラッグして幅を変える線)そのもので、枠はトランスクリプトに接しています。枠の色もその線に合わせ、ペインがキーを受け取っている間は Claude Code のアクセントの色、それ以外は薄い色にします。それより狭いときや fullscreen でない画面ではプロンプトの上に置き、結果は数行に切り詰めます。fullscreen 表示では、プロンプトの上に開いたペインは、ターミナルを 110 列以上に広げると自動で右にドックします。ドックしたペインは、ターミナルを 110 列未満に狭めると、プロンプトの上には移さずに閉じます。狭いときは、見出しを `3·2/4` のように縮めます
- キーボード操作: `/peek` で最新のページを開きます(開いていれば閉じます)。`/peek 1|2|3|4` で表示の段階を設定します。ペインがキーを受け取っている間は、Tab でボタンを移り、Enter で押します。`p` と `n` で前後のページ、`e` で最新、`r` で読み直し、矢印でスクロール、`x` か `Esc` で閉じます

## 注意

- クリックが mod に届くのは fullscreen 表示のときだけです。fullscreen でない画面(`CLAUDE_CODE_NO_FLICKER=0`、tmux の既定)では `/peek` と上のキーを使ってください
- 会話は、モデルが読む形のものを読みます。Claude Code が差し込むリマインダーは除き、スラッシュコマンドは出力を除いて `/name args` の形で表示します
- thinking は API が返した分だけ表示できます。省略・秘匿された thinking はその旨を表示します
- 呼び出しがまだ会話に入っていない、またはもう無い(圧縮済み)行では、その行自体が持っている情報を表示します
- ctrl+o や `--verbose` の表示では、行は結果も含めて Claude Code 本体に任せます
- [tool-lines](https://github.com/Tickloop/claude-mods) もツール呼び出しを畳みます。どちらか一方を入れてください

## 必要なもの

- ターミナルに [Nerd Font](https://www.nerdfonts.com/) が設定されていること

## インストール

```sh
claude plugin marketplace add tkhashi/Claude.Mods
claude plugin install peek@local-mods
```

新しいセッションを開くと読み込まれます。更新方法や開発については[リポジトリの README](../README.ja.md) を参照してください。
